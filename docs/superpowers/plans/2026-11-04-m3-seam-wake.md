# M3 Seam-Shifted Wake Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Learn, per pitcher × pitch type, the extra push (ft/s²) that M1's gravity + drag + Magnus flight is missing, predicted from release-only features, and show on held-out games that it shrinks the plate miss.

**Architecture:** `physics.py` gains an optional constant extra acceleration. `seam.py` turns each training pitch's calibrated M1 plate miss into the push that would close it, fits a fixed (mean) and a per-pitch (ridge, game-grouped CV) model, and scores M1 / M1+fixed / M1+per-pitch on held-out games with a game-level paired bootstrap. A CLI runs five real pitchers and writes `results/m3/<slug>/` and `results/M3.md`.

**Tech Stack:** Python 3.11, numpy, pandas, scipy, scikit-learn (all present), pytest.

**Spec:** `docs/superpowers/specs/2026-11-04-m3-seam-wake-design.md`

## Global Constraints

- No new dependencies.
- Type hints and docstrings on public functions; units in names or docstrings (`_ft`, `_in`, `_fts2`).
- Every modelling/physics choice gets a short *why* comment (reference where there is one: Nathan; Smith/Driveline on seam-shifted wake).
- Fixed seeds (default `seed=0`); `split_by_game` 70/30 seed 0, once per pitcher.
- Grading minimum: < 30 held-out pitches → fitted and reported, `graded=False`, `pass` NA.
- Never an input to the push model: `ax`, `ay`, `az`, `vx0`, `vy0`, `vz0`, `pfx_x`, `pfx_z`, `plate_x`, `plate_z`, or any inferred axis.
- No fitting on held-out games (ridge CV splits **training games** by game).
- Synthetic data only writes to `results/synthetic/`; synthetic rows stay labelled "Synthetic".
- Commits carry **no `Co-Authored-By` trailer**, and no other Claude attribution.

## Review Focus

1. A pitch type with only 2–4 training games: ridge CV must still run (fewer folds) and not crash. Test in Task 3.
2. Zero push (`extra_acc=None` or all zeros) must leave every M1 number bit-identical. Test in Task 2.
3. Spin axis near 0/360 must not create a jump in the push model's inputs (sin/cos). Test in Task 3.
4. A pitch type with < 30 held-out pitches must show `graded=False` and NA `pass`, never a pass. Test in Task 4.
5. A pitcher CSV with NaN in a seam feature (e.g. `release_extension`): rows dropped and counted in `skipped`, not a crash. Test in Task 4.

### Task 3: `seam.py` core — target, fits, prediction

**Files:**
- Create: `src/pitchsim/seam.py`
- Test: `tests/test_seam.py`

**Interfaces:**
- Consumes: `validation.residuals`, `validation.run_sim` (with `extra_acc`), `statcast.fit_plate_crossing`, `synthetic.make(push=...)`.
- Produces:
  - `SEAM_FEATURES = ["sin_axis", "cos_axis", "release_spin_rate", "release_speed", "release_pos_x", "release_pos_z", "release_extension"]`; `FORBIDDEN = ["ax", "ay", "az", "vx0", "vy0", "vz0", "pfx_x", "pfx_z", "plate_x", "plate_z"]`.
  - `seam_design(df) -> np.ndarray` (N × 7, from `spin_axis` → sin/cos and the other five columns; raises `ValueError` if asked for a FORBIDDEN column — it never reads them).
  - `push_target(df, cd, eff) -> np.ndarray` (N × 2, ft/s²): the constant push that closes each pitch's calibrated miss at the fit crossing, release start, `df["rho"]`. First guess `a = -2 * miss_ft / t**2`, then one correction pass (re-simulate with `a`, add `-2 * remaining_ft / t**2`), because drag makes the first guess approximate.
  - `@dataclass SeamModel(kind: str, mean: np.ndarray, pipeline: sklearn Pipeline | None, alpha: float | None, n_train: int, n_games: int)`.
  - `fit_fixed(target) -> SeamModel` (kind `"fixed"`, `mean` = column means).
  - `fit_per_pitch(train, target, seed=0) -> SeamModel` (kind `"per_pitch"`): `StandardScaler` + `Ridge` on `seam_design`, `alpha` from `GridSearchCV` over `np.logspace(-3, 3, 13)` with `GroupKFold(n_splits=min(5, n_games))` grouped on `game_pk`, scoring neg MSE. If `n_games < 2`, falls back to `fit_fixed` and says so in `kind="fixed_fallback"`.
  - `predict_push(model, df) -> np.ndarray` (N × 2).

### Task 4: `seam.py` evaluation

**Files:**
- Modify: `src/pitchsim/seam.py`
- Test: `tests/test_seam.py`

**Interfaces:**
- Consumes: Task 3; `validation.split_by_game`, `validation.calibrate`, `validation.MAX_TRAIN`, `validation.angle_diff`; `statcast.observed_break_direction_deg`; `generative.circular_mean_deg`, `fit_pitch_type`, `sample`, `generated_release_state`, `movement_in`, `MIN_TRAIN`, `MIN_TEST`.
- Produces:
  - `N_BOOT = 1000`.
  - `median_drop_ci(before_in, after_in, games, seed=0, n_boot=N_BOOT) -> tuple[float, float, float]`: (median(before) − median(after), 2.5%, 97.5%), resampling **held-out games** with replacement (pitches in a game share air and mound, the same reason the split is by game).
  - `evaluate_pitcher(df, rho, seed=0) -> tuple[pd.DataFrame, pd.DataFrame, list[str]]` = `(summary, knock_on, skipped)`.
  - `summary` one row per pitch type with columns: `pitch_type, pitch_name, n_train, n_test, n_games_train, cd, spin_eff, err_m1_in, err_fixed_in, err_per_pitch_in, bias_x_m1_in, bias_z_m1_in, bias_x_m3_in, bias_z_m3_in, drop_in, drop_lo_in, drop_hi_in, pp_vs_fixed_in, pp_vs_fixed_lo_in, pp_vs_fixed_hi_in, push_x_fts2, push_z_fts2, axis_gap_deg, alpha, model_kind, graded, pass`.
    - `err_*` are median held-out misses (in) for M1 only / M1 + fixed / M1 + per-pitch; `*_m3` biases are for per-pitch.
    - `drop_*` = `median_drop_ci(M1, per-pitch)`; `pp_vs_fixed_*` = `median_drop_ci(fixed, per-pitch)`.
    - `push_*` = training-mean target; `axis_gap_deg` = circular mean over training pitches of `angle_diff(spin_axis, observed_break_direction_deg)`.
    - `graded = n_test >= MIN_TEST and n_games_test >= 2`; `pass = drop_in >= MIN_DROP_IN (0.6) and drop_lo_in > 0` if graded else `pd.NA` (`seam.grade`). `n_games_test` sits after `n_test`.
  - Calibration exactly as M1/M2: per type, `calibrate` on training capped at `MAX_TRAIN` (`random_state=seed`), release start; push target on **all** training pitches with those Cd/eff.
  - Types with < `MIN_TRAIN` training pitches go to `skipped`; rows with NaN in any seam feature are dropped first and counted in `skipped` (as M2 does).
  - `knock_on` (reported, not graded): per pitch type, fit M2's Gaussian (`fit_pitch_type(train, mixture=False, seed)`), sample 1,000, fly with M1 only and with M1 + per-pitch push (push from `predict_push` on the samples, `rho` = training median), and compare `movement_in` x/z with held-out Statcast movement (same formula and Statcast cloud as `generative.evaluate_pitcher`). Columns: `pitch_type, variant ("m1", "m1+m3"), component ("x", "z"), ks_stat, p_value, mean_diff_in`.
